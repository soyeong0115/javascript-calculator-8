# javascript-calculator-precourse
입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

---

## 📝 구현 기능 목록

- [x] 문자열 입력받기
  - 입력값이 빈 문자열일 경우 예외 처리

- [x] 사용자가 입력한 문자열이 조건을 만족하는지 검증
  - 구분자와 양수로 구성된 문자열인지 확인  
  - 잘못된 입력값일 경우 예외 처리
    
- [x] 잘못된 값 입력 시 에러를 발생시키고 애플리케이션을 종료
- [x] 구분자를 기준으로 숫자를 분리  
- [x] 분리된 숫자들의 합을 계산
- [x] 결과 출력하기

---

## ⚠️ 예외 처리 (잘못된 입력값 사례)

### 1️⃣ 문자열 형식 오류
- 구분자와 양수로 구성되지 않은 경우 
  - 빈 문자열일 경우 0 출력
  - 숫자만 있을 경우 → `"123"`  
  - 구분자만 있을 경우 → `","`, `":"`  
  - 음수가 포함된 경우 → `"1,-2,3"`  
  - 잘못된 순서
    - 구분자로 시작하는 경우 → `",1:2"`
    - 커스텀 구분자 미정의 상태에서 양수로 시작하지 않는 경우 → `";8;3"`
    - 문자열 끝이 양수가 아닌 경우 → `"1,2,"`


### 2️⃣ 기본 구분자 오류
- 기본 구분자인 쉼표(`,`) 또는 콜론(`:`) 이외의 구분자를 사용한 경우  


### 3️⃣ 커스텀 구분자 오류
- 커스텀 구분자를 잘못 정의한 경우  
  *(문자열 맨 앞이 아니거나, `"//"`와 `"\n"` 사이에 문자가 없는 경우 등)*  
- 커스텀 구분자를 정의했지만, 다른 구분자를 사용한 경우


### 4️⃣ 구분자 반복
- 구분자를 연속으로 사용한 경우  
  예: `"1,,2"`, `"1::2"`
